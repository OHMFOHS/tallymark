## Reproduce from the checkout

Use Node 24 or 26 for the external harness. The pinned TypeScript reference packages require Node 24+. The kit itself supports Node 22.12+. Install pnpm 9.15.0, Git, uv 0.9.28 and Python 3.13. Dependency installation on a fresh machine needs network access. The tests use stdio and loopback HTTP.

```sh
pnpm install --frozen-lockfile
pnpm build
npm ci --prefix integrations/reference --ignore-scripts --no-audit --no-fund
uv python install 3.13
uv sync --locked --no-install-project --project integrations/reference
pnpm test:reference
```

The harness constructs YAML with temporary absolute paths and invokes the public CLI for discovery, execution and JSON replay. It checks tool names, protocol, actual reply sequence, call counts, verdicts, exit codes and independent state. Each run writes to a fresh `artifacts/reference/run-*` directory. The harness succeeds when the expected experimental results match. A verified gate running the CLI still requires exit 0. [Harness](../scripts/reference-interop.mjs) · [npm lock](../integrations/reference/package-lock.json) · [Python lock](../integrations/reference/uv.lock)

## Integration difficulties

- The Memory server resolves its default graph path next to its installed module. The harness explicitly passes an absolute `MEMORY_FILE_PATH` via the trusted launcher. Relative paths can inspect the wrong graph.
- An initial Git experiment created a branch, then looked for a per-branch reflog. The ref existed while the observer found no matching log. The result was INCONCLUSIVE. The recorded harness uses commit history in a private repository where only forward commits are scheduled. It does not generalize this counter to rewritten histories.
- The upstream servers do not export this kit's terminal attempt IDs. Returning success, seeing a final file, or counting a matching commit cannot establish whether further work is pending. A trusted exporter must join the operation key and attempt metadata to the authoritative downstream commit or job lifecycle before a verified PASS is possible.
- SDK negotiation can start a stdio process twice. Start side-effect-free processes and scope their data paths explicitly. The harness gives Filesystem its directory, Git its repository, and the HTTP client exactly one loopback URL.

## Specification and conformance

The official current revision on the review date is 2026-07-28. Modern requests carry protocol metadata per request. Older peers can negotiate a version with an initialize handshake. Modern stdio cancellation uses a request-ID notification. For a streaming HTTP request the disconnect signals cancellation. Neither signal establishes rollback. Local controls cover modern stdio/HTTP cancellation after commit and legacy 2025-11-25 stdio cancellation and HTTP session deletion. The external-server matrix above measures the listed operations. Official MCP conformance and certification are separate. [External reports](../integrations/evidence/2026-11-21)                                                                                             |

The current milestone addresses result validity and runner journaling first. Stale-lock recovery, OS isolation, unsigned artifacts and exporter fidelity remain documented constraints.
